# Scope

## MVP Objective

Create a working system that discovers and prioritizes job opportunities in Irvine for a frontend/fullstack developer.

## Core Capabilities

1. Company discovery
2. Job ingestion
3. Data normalization
4. Relevance scoring
5. Dashboard visualization

## Inputs

- company names
- company websites
- career page URLs
- job board links
- user profile/preferences

## Outputs

- prioritized company list
- prioritized job list
- fit score per role
- categorized tech stack
- apply-now / watchlist suggestions

## Constraints

- solo project
- limited time
- focus on MVP first
- avoid over-engineering

## Non-Goals

- auto-apply
- recruiter outreach
- cover letter generation
- broad nationwide search
- deep ML training from scratch
